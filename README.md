# 🤖 بوت تيليجرام لتبديل الوجه بالذكاء الاصطناعي

بوت تيليجرام احترافي وكامل لتغيير الوجه في **الصور والفيديوهات** باستخدام مكتبة
InsightFace (`inswapper_128.onnx`)، مبني على **Webhook فقط** وجاهز للنشر على
**Render مجاناً**.

> ⚠️ **ملاحظة قانونية وأخلاقية:** استخدم البوت فقط على الوجوه التي تملك الحق في
> استخدامها (صورك أنت، أو صور وافق أصحابها). لا تستخدمه في انتحال الهوية أو نشر
> المحتوى المضلل.

---

## ✨ المميزات

| الميزة | الوصف |
| --- | --- |
| 🖼️ تبديل وجه في الصور | إرسال صورتين (المصدر + الهدف) واستلام النتيجة |
| 🎥 تبديل وجه في الفيديو | إرسال صورة + فيديو (حتى 20 ثانية) واستلام الفيديو الناتج |
| 🔧 تحسين الجودة | تحسين CLAHE + تقليل الضوضاء + توضيح (3 مستويات: عالي/متوسط/بدون) |
| 🖥️ لوحة مطور كاملة | إحصائيات، إرسال جماعي، رسائل مباشرة، حظر/فك حظر، نسخ احتياطي، تنزيل/رفع قاعدة البيانات، مسح الكاش، تشغيل/إيقاف البوت |
| 👁️ مراقبة شفافة | المستخدم يوافق أولاً، وكل رسالة تُسجَّل وتُحول للمطور مع أزرار (رد/حظر/حذف) |
| 🗄️ قاعدة بيانات SQLite | تخزين المستخدمين والرسائل والعمليات والنسخ الاحتياطية |
| 🛡️ حماية | معدّل طلبات، فحص حجم الملفات، فحص الوجوه، رمز سرّي للـ Webhook |
| 🧹 تنظيف تلقائي | حذف الملفات المؤقتة كل 30 دقيقة |

## 🚀 التشغيل المحلي

### 1) المتطلبات
- بايثون **3.11** (يفضَّل — الملف `.python-version` يضمنها)
- توكن بوت من [@BotFather](https://t.me/BotFather)
- (اختياري) `ffmpeg` لضغط الفيديو مع الصوت. إن لم يتوفر يعمل البوت بالفيديو بدون صوت.

### 2) التثبيت

```bash
# إنشاء بيئة افتراضية وتفعيلها
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux / Mac:
source .venv/bin/activate

# تثبيت المكتبات
pip install -r requirements.txt
```

### 3) الإعدادات

انسخ `.env.example` إلى `.env` واملأ القيم:

```bash
cp .env.example .env
```

| المتغير | الوصف | مطلوب؟ |
| --- | --- | --- |
| `BOT_TOKEN` | توكن البوت من BotFather | ✅ |
| `PUBLIC_URL` | الرابط العام للتطبيق (مثل `https://your-app.onrender.com`) | ✅ |
| `DEV_ID` | معرف تيليجرام للمطور (رقمي) | ✅ |
| `ENABLE_MONITORING` | تشغيل المراقبة الشفافة `true` | لا |
| `MAX_IMAGE_SIZE_MB` / `MAX_VIDEO_SIZE_MB` | حدود الأحجام | لا |
| `MAX_VIDEO_DURATION_SECONDS` | أقصى مدة فيديو | لا |

### 4) التشغيل

```bash
uvicorn main:app --host 0.0.0.0 --port 8000
```

- البوت يتصل تلقائياً بالـ Webhook عند بدء التشغيل.
- فحص الصحة: `GET /health` يعيد `{"status": "ok"}`.
- المعرّف السري للـ Webhook يُشتق تلقائياً من التوكن، لذا كل ما عليك هو `PUBLIC_URL`.

## ☁️ النشر على Render (مجاناً)

1. ادفع المشروع إلى مستودع GitHub.
2. في [render.com](https://render.com) أنشئ **Web Service** جديداً واربط المستودع.
3. ستُستخدم `render.yaml` تلقائياً أو املأ يدوياً:
   - **Runtime:** Python 3
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `uvicorn main:app --host 0.0.0.0 --port $PORT`
   - **متغيرات البيئة:**
     - `BOT_TOKEN` = توكن البوت
     - `PUBLIC_URL` = `https://<اسم-التطبيق>.onrender.com`
     - `DEV_ID` = معرف المطور
4. بعد النشر اضغط زر **Manual Deploy** إذا لزم.
5. تحقق من `https://<اسم-التطبيق>.onrender.com/health`.

> تيليجرام يتطلب **HTTPS** لضبط الـ Webhook — Render يوفره تلقائياً.
> إن أردت نسخة مبسطة، انشر على [Render بلو بيلز](https://bluesight.tech) أو أي خدمة أخرى تدعم Webhook.

## 🛡️ المراقبة الشفافة

- قبل أول استخدام يقرأ المستخدم التنبيه ويوافق عليه بالضغط على **«أوافق وأتابع»**.
- عند تفعيل `ENABLE_MONITORING` تُحول رسائل المستخدمين إلى المطور مع زر **«رد»** و**«حظر»** و**«حذف»**.
- رفض المراقبة يمنع استخدام البوت.
- كل ذلك موثق في [`CHANGELOG.md`](CHANGELOG.md).

## 🧑‍💻 لوحة المطور

يفتحها المطور (`DEV_ID`) بزر **«لوحة المطور»** من القائمة الرئيسية، وتشمل:

- الإحصائيات الكاملة (مستخدمون، عمليات صور/فيديو، فاشلة...).
- آخر المستخدمين والرسائل والأخطاء.
- إرسال جماعي (Broadcast).
- رسالة مباشرة لمستخدم / حظر / فك حظر / حذف.
- تشغيل وإيقاف استقبال الرسائل.
- مسح الكاش، تنزيل/رفع/نسخ/استعادة قاعدة البيانات.
